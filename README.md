# Women Empowerment
live link : - 
https://skuser2005.github.io/Women-Empowerment/



An advanced and modern Women Empowerment NGO Website built using **HTML, CSS, and JavaScript**.


<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/960f8b99-c89a-4d75-baf0-3ab326c5ec04" />

This project focuses on empowering women through technology, awareness, education, healthcare, and leadership initiatives. The website includes a modern responsive design, dark/light mode, animations, interactive UI, donation and volunteer forms, image gallery, testimonials, and professional UI/UX.
